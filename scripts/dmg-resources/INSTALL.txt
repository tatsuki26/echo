Echo インストール手順（公証前ベータ版）
================================

※ 初回は macOS のセキュリティでブロックされることがあります。
  右クリックだけでは開けない場合は、下記「方法B」を試してください。


【方法A】ターミナル（最も確実）
--------------------------------

1. Echo.dmg をダウンロード（通常は「ダウンロード」フォルダ）

2. ターミナルを開き、次をコピー＆ペーストして Enter:

   xattr -cr ~/Downloads/Echo.dmg && open ~/Downloads/Echo.dmg

3. 開いたウィンドウで Echo.app を Applications にドラッグ

4. もう一度ターミナルで:

   xattr -cr /Applications/Echo.app && open /Applications/Echo.app


【方法B】システム設定から許可
--------------------------------

1. Echo.app を一度普通にダブルクリック（ブロックされる）

2. システム設定 → プライバシーとセキュリティ

3. 下の方に「“Echo”は開発元を確認できないため使用がブロックされました」
   と表示されていれば → 「このまま開く」をクリック

4. 再度 Echo を開く


【うまくいかない場合】
--------------------------------

- Echo.app は必ず Applications フォルダに入れてから起動
- 古い Echo が動いていたら終了してから再試行
- それでもダメなら方法Aのターミナル手順を試す
