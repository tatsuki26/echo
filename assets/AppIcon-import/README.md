# AppIcon インポート用フォルダ

サイズごとに用意した PNG をこのフォルダに入れて、次を実行してください。

```bash
./scripts/install-app-icons.sh
```

## 推奨ファイル

次のいずれかの形式で OK です。

- `16.png`, `32.png`, `64.png`, `128.png`, `256.png`, `512.png`, `1024.png`
- `icon_16x16.png` など Xcode 形式のファイル名
- サイズがバラバラでも、最大サイズ（1024px 推奨）だけでも自動リサイズされます

## 注意

- 正方形の PNG を推奨
- 1024×1024 を必ず含めると品質が最も良くなります
